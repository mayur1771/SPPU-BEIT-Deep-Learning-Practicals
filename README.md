# SPPU-BEIT-Deep-Learning-Practicals

This repository contains 6 Deep Learning practicals implemented using Python and popular libraries.

### Practicals Covered
1. Study of Deep Learning Packages
2. Feedforward Neural Network
3. Image Classification using CNN
4. Anomaly Detection using Autoencoder
5. CBOW Word2Vec Model
6. Object Detection using YOLOv8

**Technologies:** Python, TensorFlow, Keras, NumPy, Matplotlib, Gensim, NLTK, and Ultralytics.

**Datasets:** MNIST, NLTK Gutenberg Corpus, and COCO128.

Created for SPPU BE Information Technology students for practical learning and reference.
